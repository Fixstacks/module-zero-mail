# Zero_Mail

How the store's emails leave, and a log of each. Transport:
Magento's own, Amazon SES via its API with the server's AWS role, or none.
Email Log (Marketing > Communications) with Resend. Test addresses
(example.com, ...) are logged, not sent. One sender for all emails, and a
Send Test Email button.

## Install

Requires Magento Open Source 2.4.7–2.4.9 and PHP 8.2–8.4.

```bash
composer require fixstacks/module-zero-mail
bin/magento setup:upgrade
bin/magento setup:di:compile           # production mode
bin/magento setup:static-content:deploy # production mode
bin/magento cache:flush
```

Composer installs `fixstacks/module-zero-core` with it.

Part of [`fixstacks/zero`](https://fixstacks.com/zero), which installs the Zero theme and every Zero module at once.
